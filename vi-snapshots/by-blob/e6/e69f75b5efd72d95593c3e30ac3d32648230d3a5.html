    <strong>averaging parameters</strong> is a cluster that defines how this VI computes the averaging. The specifications of the parameters include the type of averaging, the type of weighting, and the number of averages.

      		averaging mode

      <strong>averaging mode</strong> specifies the averaging mode.

      		weighting mode

      <strong>weighting mode</strong> specifies the weighting mode for RMS and vector averaging.

      		number of averages

      <strong>number of averages</strong> specifies the number of averages used for RMS and vector averaging. If <strong>weighting mode</strong> is exponential, the averaging process is continuous. If <strong>weighting mode</strong> is linear, the averaging process stops after this VI computes the selected <strong>number of averages</strong>.
